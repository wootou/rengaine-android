# Rengaine for Android

**English** | [Français](README.fr.md)

The Android app for **Rengaine**, the self-hosted music server. It connects to your Rengaine server so you can listen to your library anywhere, at home or on the go.

🌐 **Website and documentation: [rengaine.org](https://rengaine.org)** · Server: [wootou/rengaine](https://github.com/wootou/rengaine)

**Status:** release candidate (1.0.0-rc), being tested.

## Features

- **QR code pairing** with your server, nothing to type.
- **Synced with the web player**: queue, favourites, playlists, history and settings.
- **Mobile-friendly**: on-the-fly conversion to save data on slow connections.

## Install

Download the APK from the [releases](https://github.com/wootou/rengaine-android/releases). A Play Store release is planned.

Requirements: a [Rengaine](https://github.com/wootou/rengaine) server and Android 12 or later.
