# Rengaine pour Android

[English](README.md) | **Français**

L'application Android de **Rengaine**, le serveur de musique à héberger soi-même. Elle se connecte à votre serveur Rengaine pour écouter votre bibliothèque partout, à la maison comme en déplacement.

🌐 **Site et documentation : [rengaine.org](https://rengaine.org)** · Serveur : [wootou/rengaine](https://github.com/wootou/rengaine)

**Statut :** release candidate (1.0.0-rc), en cours de test.

## Fonctionnalités

- **Appairage par QR code** avec votre serveur, sans rien taper.
- **Synchronisé avec le lecteur web** : file d'attente, favoris, playlists, historique et réglages.
- **Adapté au mobile** : conversion à la volée pour économiser les données sur les connexions lentes.

## Installation

Téléchargez l'APK depuis les [releases](https://github.com/wootou/rengaine-android/releases). Une publication sur le Play Store est prévue.

Prérequis : un serveur [Rengaine](https://github.com/wootou/rengaine) et Android 12 ou plus récent.
